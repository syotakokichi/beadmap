# /boundary-check - push 前の境界チェックゲート

push 前の境界チェックゲートを実行してください。

## 手順

1. `scripts/boundary-check.sh` を実行する（fail-closed: 語リストが読めなければ exit 1 で停止）
2. 5 項目チェックリスト（[boundary-check ルール](../rules/boundary-check.md)）を確認する:
   - [ ] 禁止語 grep 0 件（スクリプトの OK 出力を確認）
   - [ ] 公開前チェック 4 点（自作コード / 自分の環境のスクショのみ / 引用なし / 有料コンテンツをなぞらない）
   - [ ] 入力ソース宣言（公開可能な情報のみを入力にしている）
   - [ ] devlog 境界（意思決定支援ツールは採用結果・理由のみ）
   - [ ] スクリーンショット境界（公開スクショは目視確認し、確認日・観点を devlog に記録）
3. チェック結果を `docs/devlog/` の当日エントリに記録する（語リストの内容は書かない）
4. 全項目 OK の場合のみ push する。NG が 1 つでもあれば push しない

## 注意

- スクリプトが NG を出した場合は該当箇所を修正し、再実行で OK になるまで push しない
- 未追跡ファイルも検査対象（`.gitignore` 対象は除外）。コミット前の作業ファイルにも注意する
